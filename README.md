# Figma Backup для macOS

Локальные резервные копии проектов и файлов Figma. macOS 13+ на Apple Silicon.

## Скачать

[Последняя версия и DMG](https://github.com/eduvedu/figma-backup-releases/releases/latest).

Откройте DMG и перенесите Figma Backup в «Программы». При обновлении дождитесь завершения бэкапа и закройте приложение перед заменой. Проекты, настройки и копии хранятся отдельно от приложения.

В этом репозитории публикуются готовые выпуски и контрольные суммы. Исходный код хранится отдельно в приватном репозитории.

## Обновления

Начиная с 0.7.0 приложение проверяет новые версии на GitHub и предлагает скачать DMG. Автопроверку можно отключить в Настройках. Установка выполняется вручную; автоматического перезапуска и замены приложения нет.

Пользователям 0.6.9 нужно один раз установить 0.7.0 вручную.

## Проверка файла

У каждого выпуска есть SHA256SUMS.txt. Скачайте его рядом с DMG и выполните в Терминале:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Сборки имеют локальную ad-hoc подпись, без Developer ID и нотарификации Apple. На корпоративном Mac согласуйте установку с IT.
