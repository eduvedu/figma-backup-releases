# Figma Backup для macOS

Локальные резервные копии проектов и файлов Figma. macOS 13+ на Apple Silicon.

## Скачать

[Последняя версия и DMG](https://github.com/eduvedu/figma-backup-releases/releases/latest).

Откройте DMG и перенесите Figma Backup в «Программы». При обновлении дождитесь завершения бэкапа и закройте приложение перед заменой. Проекты, настройки и копии хранятся отдельно от приложения.

В этом репозитории публикуются готовые выпуски и контрольные суммы. Исходный код хранится отдельно в приватном репозитории.

## Как обновить приложение

Приложение автоматически проверяет наличие новых версий и сообщает о них. **Скачивание и установка каждой новой версии выполняются вручную:** автоматической замены приложения и перезапуска пока нет.

1. Нажмите «Скачать DMG» в приложении или скачайте файл `.dmg` из [последнего релиза](https://github.com/eduvedu/figma-backup-releases/releases/latest).
2. Дождитесь завершения текущего бэкапа и закройте Figma Backup через меню приложения → «Завершить» (⌘Q).
3. Откройте скачанный DMG.
4. Перетащите Figma Backup в папку «Программы» (Applications) и подтвердите «Заменить».
5. Запустите Figma Backup из «Программ».

**Удалять старую версию заранее не нужно.** При обычной замене приложения проекты, настройки, сессия входа в Figma и сохранённые копии остаются на месте. Не удаляйте папку данных приложения в Library и выбранную папку резервных копий.

В версии 0.6.9 проверки обновлений ещё нет: скачайте 0.7.0 или более новую версию со страницы релизов и выполните те же шаги. Начиная с 0.7.0 автопроверку можно отключить в Настройках.

## Проверка файла

У каждого выпуска есть SHA256SUMS.txt. Скачайте его рядом с DMG и выполните в Терминале:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Сборки имеют локальную ad-hoc подпись, без Developer ID и нотарификации Apple. На корпоративном Mac согласуйте установку с IT.
